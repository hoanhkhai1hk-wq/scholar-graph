### 1.2 抽到的样式与是否采纳

抽到的样式是"个人/团队主页：居中排版的问候语作 h1，下面每个数字用常规字重放在色阶面板上"。

**未整体采纳**，理由可陈述（SKILL.md 允许，要求写明）：它描述的是"个人/团队主页"的问候式首屏，与研枢"论文库 + 工作台"的首屏任务不符；且用户已明确选定功能卡片编排为**紧凑仪表盘 Bento**（数据、操作、内容同屏，入口最全，密度高），与居中问候式版面冲突。

**采纳的部分**（app-screens 章法，与本项目红线一致）：

| 章法 | 本单落实 |
| --- | --- |
| 颜色用在数据上，不在装饰上（中位约 3% 彩色像素；23 个样本中 12 个没有实心主按钮） | 赭石只用于警示与强调，深松绿只用于主按钮与当前项，其余保持纸面 |
| 指标是字，不是"图标+彩色圆"卡片；不画迷你走势线 | Bento 三个指标是 26px 常规字重数字，无图标圆、无 sparkline |
| 表面是平的（23 个中 17 个无阴影，靠 1px 线或一个色阶分隔） | 卡片一律 1px 边框，无投影；分隔只用发丝线 |
| 没有"英雄头部"（9 个屏幕没有超过 16px 的标题） | 页面标题保持正文级，不放大成 hero |
| 导航后退：当前项是中性灰底或文字色变化，彩色左侧条只出现一次 | 当前项只用深松绿文字 + 2px 下边线，不用彩色药丸 |
| 表格是线与对齐：无斑马纹、无表头色带、数字右对齐 | 沿用既有表格样式，未加斑马纹 |
| 数据状态诚实：0 打印为 0，缺失是灰横杠，空区块保留边框 | 空状态组件保留外框与说明，不隐藏区块 |

### 1.3 档位

**动效低 / 密度中 / 布局中**：

- **动效低**：动效只给图谱与阅读器跳转（这两处已有，本单未新增）；骨架屏只有一层极缓的透明度呼吸，且包在 `prefers-reduced-motion: reduce` 里关掉。
- **密度中**：Bento 12 列网格、指标卡 26px 数字、入口卡 150px 起自适应，列表保持既有行高不做压缩。
- **布局中**：仅首页换成 Bento，其余页面版式不动。

### 1.4 借鉴章法的取舍

- **借鉴 federicopian 4 点**：字体层级（指标用字不用图标）、克制配色系统（一个强调色 + 中性底）、圆形母题（空状态图示用同心圆，非 emoji）、留白层级（区块之间靠间距而非卡片边框堆叠）。
- **不学 4 点**：滚动劫持、超大标题挤掉功能、全屏氛围 morph、人味装饰（挥手、"Welcome back"这类）——全部未采用。
- **视频卡章法**：入口卡按"视觉 → 标题 → 元信息"排，统一网格，悬停反馈只做边框与底色变化（120ms）。只学章法，无样式素材搬运。
- **用户选定编排**：紧凑仪表盘 Bento——数据、操作、内容同屏，入口最全（5 个入口卡），密度高。
- **未做的**：液态玻璃（不进）、瀑布流（不换，Bento 网格已够）。
