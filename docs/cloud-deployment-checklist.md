# 云服务器与评审体验就绪清单

状态：文档侧就绪；服务器采购、备案/域名事项、实际部署、视频拍摄和比赛网站提交由作者另行推进。本表未勾选的项目不代表线上通过。在线演示地址：**待实际部署填写**；不得用localhost、临时登录页或未经验证的隧道地址替代。

## 部署前

- [ ] 选定大陆评委可达的实际服务器地域、域名和HTTPS方案，按所用服务商要求处理必要手续；不以本机测试承诺国内访问速度。
- [ ] 核对服务器CPU、内存、磁盘、带宽和可用空间，记录真实配置。本机容器2核4G配额不等于云服务器已达到可用性能；BGE、OCR与批量解析应做容量验证。
- [ ] 固定经检查的main提交，完整保留Git历史。按Dockerfile首次构建，或从自己真实发布的镜像部署；本机item08标签不是公网镜像。
- [ ] 审核本项目MIT与第三方引擎、字体、模型的许可证。FlagEmbedding及BGE权重许可仍待核，不在未审核时打包模型或字体分发。
- [ ] 准备个人库与评审库分离的卷，只放获准展示的材料；不复制个人会话和真实Key入镜像。

## 环境、访问与数据

- [ ] 按[部署指南](deployment-guide.md)创建本地.env及override变量引用，填真实服务配置；修改后up -d backend，再实跑摘要和全文翻译。仅KEY_SET不够。
- [ ] 前后端healthy、前端容器能解析backend；容器通信使用8000，后端不直接公开。重启Docker和服务后复查。
- [ ] 配置反向代理、HTTPS、域名以及评审访问码或测试账号；SG_REVIEW_CODE、签名和服务令牌使用新的随机值，仅后端保存。生产Cookie启用安全属性。
- [ ] 使用实际浏览器核对未授权访问、错误码、注销、过期、内部API保护及论文下载；不得只保护首页而公开后台数据。
- [ ] 配置上传大小与超时、PDF Range转发、流式不缓冲、取消与刷新恢复，代理中断时显示错误原因。限制并发、磁盘和演示库容量。
- [ ] 备份原PDF、冻结解析、SQLite操作记录及必需配置的安全副本，向新空目录恢复并逐项核对哈希。不得只保存镜像而丢卷。

## 上线验收与维护

- [ ] 导入实际演示材料并执行预热；记录首事件、首内容增量和校验final。缺向量时记录词法回落；RRF不能标成reranked。
- [ ] 从至少一个实际大陆网络和独立设备打开HTTPS页面，测试论文库、上传、阅读末页、问答锚点、翻译、图谱、检索失败与重试；记录真实时间、网络和截图，不填估算延迟。
- [ ] 验证研究助手不再对普通概括一律拒答；也验证无依据问题会拒答。图谱引用不越出选择集合，推荐反馈影响排序。
- [ ] 重启后论文、版本选择、会话与任务状态保留；监测内存、OOM、磁盘、任务积压和上游限额。日志不得记录Authorization和Key。
- [ ] 使用匿名评审窗口按视频同样步骤完整走一遍，再填写真实在线地址与评审专用访问说明。账号/访问码通过比赛指定渠道提交，不放公开仓库。
- [ ] 评审期间保持服务器、域名、模型额度和HTTPS可用，确定故障联系人和回滚版本；线上变更后重新测试。正式提交后的变更遵守组委会规则。

目前没有公网延迟、可用率、云内存峰值或备份恢复实测结论；清单本身不能作为这些项目的通过证据。
