## 目录来源说明

本文件所列封面信息 + 十二节，**已按总指挥正式《技术文档初稿 v1》目录校对**，以正式目录为准。

上一单因在仓库、历史对话、磁盘三处均未检索到初稿原文，曾依据仓库现有材料推定过一份十二节目录。**该推定目录整体作废**，不再作为撰写依据。本次校对的处理方式：

1. 正式目录与推定目录能对上的章节，其「材料来源」与「依赖关系」两栏**直接沿用**，仅按新章节标题调整归并范围。
2. 正式目录新增而推定目录没有的章节，按新章节重新写「要补什么材料」，并标为「新增」。
3. 推定目录有而正式目录没有的章节，其内容按主题归并入正式目录的相关章节，未采用的部分丢弃，不做保留性续写。

每节表格末尾一行「目录校对」记录该节属于**沿用／改写／新增**，便于总指挥复核有无丢材料。

本文件仍然只登记「要什么、从哪来、卡在谁身上」，不含任何章节正文，也不含任何已完成的实测结论。
