# 三分钟演示指南

本指南只写本机真实跑通过的命令与实际会看到的内容。所有输入为自制样例 PDF 或你自己的论文；
**官方三用例未运行，问答与草稿均为摘录式，不调用大模型**。

前置要求：Windows + Python 3.12 + Node.js 18+。首次需安装依赖（见第 1 步）。

## 第 0 步　安装依赖（仅首次，约几分钟）

仓库根目录的 PowerShell：

```powershell
py -V:Astral/CPython3.12.15 -m venv backend/.venv
backend/.venv/Scripts/python.exe -m pip install -e 'backend[ocr,test]'
```

另开一个终端：

```bash
cd frontend
npm install
```

说明：扫描件走 PaddleOCR，首次运行会下载模型；纯文本解析装 `backend[test]` 即可。

## 第 1 步　启动后端（一条命令）

仓库根目录的 PowerShell：

```powershell
backend/.venv/Scripts/python.exe -m uvicorn scholar_graph.api:create_app --factory --host 127.0.0.1 --port 8000 --no-access-log
```

**预期看到**：`Uvicorn running on http://127.0.0.1:8000`。
可用 `http://127.0.0.1:8000/api/v1/papers` 验证，返回一段以 `{"items":` 开头的 JSON。

## 第 2 步　启动前端（一条命令）

另开一个终端：

```bash
cd frontend
npm run dev
```

**预期看到**：`✓ Ready in 3.3s`（时间因机器而异）。本机实测 `GET / 200`。

## 第 3 步　打开浏览器

访问 <http://127.0.0.1:3000>。

**预期看到**：「论文库」页面，顶部状态条右侧显示 `数据后端 http://127.0.0.1:8000/api/v1`。
首次为空列表（`total 0`），页面会写「本页无记录」，不会编造条目。

## 第 4 步　上传一篇 PDF

点顶部「上传」，选一个本地 PDF（自制样例或你自己的论文；官方 `pdf/` 用例文件不随仓库分发）。

**预期看到**：

- 文本 PDF 通常数秒返回；**扫描件需 OCR，实测约 35 秒**，期间显示「已等待 N 秒」，
  这是真实等待时长，后端没有进度事件，页面不伪造百分比。
- 成功后出现绿色「成功」标签、`paper_id` 和「查看该论文详情」链接。
- 换成一个 `.txt` 再试会得到红色错误态：HTTP 415 / `UNSUPPORTED_FILE_TYPE` /「上传文件必须为 PDF。」
  ——失败也如实显示，不静默吞掉。

批量上传可一次选多个文件（字段名 `files`），结果按 `succeeded / failed /
succeeded_count / failed_count` 四项展示，成功数与失败数之和等于提交数，整批不丢项。

## 第 5 步　看列表

回到「论文库」。

**预期看到**：刚上传的论文出现在表格里，含标题、作者、年份、版本、页数、
文本层标记（扫描件显示「无」）、`arXiv —` / `DOI —` 标识，以及分页信息
`第 1 / 1 页 · total N · has_next false`。列表底部是「能力索引」，链接到下面各页。

## 第 6 步　点进详情看分块与引用对应

点标题进入 `/papers/{id}`。

**预期看到**：

- **解析状态**：`completed`、进度条 100%，下方标注「已停止轮询：状态进入终态」。
- **分块列表**：每行有物理页码、章节路径（`H1 / H2 / H3`）、正文、类型（text/table/…）、
  归一化 bbox 和 `chunk_id`，默认每页 20 条，底部有上一页/下一页。
- **参考文献**：`[1]` 起的编号条目，含作者、年份、出处、DOI。
- **正文 ↔ 文末 对应关系**：引用序号、所在页、所在分块、目标条目。
- **去重与版本差异**：只有新版论文才有记录；旧版会显示
  「暂无去重记录（后端返回 404，该论文不是新版）」，页面不编造假记录。

## 第 7 步　其余能力页（均已接线）

| 页面 | 玩法 | 预期看到 |
| --- | --- | --- |
| 问答 `/qa` | 勾选一篇，输入「本文样本量是多少？」 | 回答按「【证据 A】原文」分块，每个事实带四字段锚点；问一个不存在的前提会 `refused=true` 并原样展示拒答原因 |
| 图谱 `/graph` | 勾选两篇论文，点「生成图谱」 | 节点表（PageRank 与层级）、边表、基石/衍生/孤立分层；无锚点的边标 `unverified` |
| 检索 `/retrieval` | 输入关键词检索 | 结果上方三枚标签直接来自响应头：`检索模式：词法兜底 lexical`、`向量状态：NOT_ENABLED`、`结果原因：OK` |
| 写作 `/writing` | 勾选论文生成框架 → 生成摘录草稿；或传一个 CSV 画图 | 框架章节与待写要点（原文摘录）；草稿逐条 `verified / unverifiable`；图表下方有图注数字与 CSV 行列的回溯表 |

阅读器在详情页点「打开阅读器」进入：左侧章节导航（按 `section_path` 与物理页码），
点正文里的 `[1]` 跳到文末条目，点文末条目跳回引用它的分块；划词只显示原文与锚点。

## 已知限制（演示时会真实遇到）

- 问答与摘录草稿是**本地确定性原文摘录**，不是大模型自由生成；问法太偏会拒答。
- 版式原文渲染与划词翻译**均未实现**：前者等后端文件端点，后者等后端模型接入，
  页面在对应位置都有明标。
- 图谱为表格展示，未接图形库；检索默认词法兜底，向量检索需后端显式开启。
- 官方三用例未运行；本指南全部结果来自自制样例与真实请求，不代表真实论文质量。
